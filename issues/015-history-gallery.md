# Issue #015: [機能追加] 過去の生成音源を一覧・試聴・設定復元できる生成履歴ギャラリー機能

## 1. 目的・概要
生成された音源をその場で聴き比べたり、過去に作った楽曲のシード値やプロンプトを再利用してバリエーション展開（再生成）ができるよう、UI上に「生成履歴（History Gallery）」を実装する。

## 2. タスクリスト
- [x] 開発用ブランチ `feature/15-history-gallery` の作成
- [x] `core/history.py` の新規作成
  - `HistoryItem` データクラスの定義
  - サイドカーJSONメタデータ保存関数（`save_metadata`）
  - 過去音源一覧ロード関数（`load_history`）
  - メタデータ未作成の古いWAV用ファイル名フォールバックパーサー（`parse_from_filename`）
- [x] `core/generator.py` の更新
  - 音声書き出し成功時にサイドカーJSONを自動生成して保存
- [x] `ui/gradio_app.py` の更新
  - 右カラムに「📜 生成履歴 (History Gallery)」アコーディオンを配置
  - 履歴ドロップダウンの選択時にオーディオプレイヤーへの即時読み込み（試聴）
  - 「📋 選択した音源の設定を入力フォームに復元」ボタンの実装（プロンプト・ネガティブプロンプト・BPM・秒数・シード値を復元）
  - 「🔄 更新」ボタンによる最新一覧の再読み込み
  - 新規音楽生成完了時に履歴ドロップダウンを自動更新する連携配線
- [x] 単体テスト・検証
- [x] ドキュメント（`README.md`, `issues/`）の更新
- [x] リモートへプッシュ & プルリクエスト作成

## 3. 実装ウォークスルー・動作確認結果
- `python3 -m py_compile ui/gradio_app.py core/history.py core/generator.py` にて構文整合性を検証。
- 単体テストにて以下を実証済み：
  1. ファイル名からのBPM/秒数/シード値のフォールバックパース（既存ファイル対応）
  2. 生成時のサイドカーJSON保存と、長い元プロンプト・ネガティブプロンプトの完全復元
  3. 新しい順（降順）でのソートとUI表示ラベル生成
- UI上で履歴音源を選択するとプレイヤーに即座にロードされ、復元ボタンを押すとシード値固定モード（`interactive=True`）としてフォームに設定が復元されることを確認。
